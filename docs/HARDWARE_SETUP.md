# Hardware Setup

## Physical Configuration

![Hardware Setup](hardware-setup.jpg)

The accident alert system uses the following hardware components:

- **Raspberry Pi** - Main processing unit running the alert system software
- **GPS Module** - For location tracking and accident detection via acceleration sensors
- **Connectivity Module** - WiFi/Network module for communication
- **LED Indicator** - Status indicator (shown in red in the setup)
- **Power Supply** - Connected via colored wiring (orange, blue, green)

### Wiring Configuration

The system uses color-coded wiring for easy assembly and maintenance:
- **Orange wires** - Power supply
- **Blue wires** - Ground connections
- **Green wires** - Data/Signal lines
- **Gray wires** - Additional connections as needed

This modular setup allows for easy testing, debugging, and component replacement during development and deployment phases.
